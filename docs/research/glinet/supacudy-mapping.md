# 对照 SupaCudy

把观察到的功能逐项映射到 SupaCudy：做不做、什么时候做、用 OpenWrt 的什么实现、哪里打算做得不一样。

优先级：**P0** 阶段 1（MVP），**P1** 阶段 2，**P2** 阶段 3，**—** 不做。

## TR3000 和观察机型的差异

| 项目 | GL-MT300N-V2（观察机型） | Cudy TR3000 |
|---|---|---|
| 无线 | 2.4GHz 单频 | 2.4GHz + 5GHz（WiFi 6） |
| WAN / LAN | 百兆 | 2.5G WAN + 1G LAN |
| USB | 2.0 | 3.0 |
| 闪存 | 16MB | 128MB / 256MB |
| 拨动开关 | 有 | 待真机确认 |

所以 SupaCudy 的无线页要按"频段 × 主 / 访客"做 4 个入口，并且有足够空间装 AdGuard Home、Tailscale 等应用。

## 全局

| GL 的做法 | 优先级 | SupaCudy |
|---|---|---|
| 左侧导航 + 卡片式内容区 | P0 | 保留思路；宽屏用双栏利用右侧空白，手机端用底部或抽屉导航，按产品规则单独设计手机布局 |
| 首页拓扑图（上网方式 → 路由器 → 客户端） | P0 | 保留，这是最好的"一眼看懂"设计；手机端做成竖向的状态卡 |
| 主题：默认 / 经典 / 暗色，存在浏览器 | P0 | 系统 / 亮色 / 暗色三档，默认跟随系统 |
| 8 种语言，存在路由器 | P0 | 只做简体中文和英文，存在浏览器 |
| 中文界面隐藏 VPN | — | 不按语言裁剪功能 |
| 说明横幅、ⓘ 气泡、⚠ 禁用原因 | P0 | 保留，做成通用组件 |
| 改动后才能点"应用" | P0 | 保留 |
| 应用后只有短暂 "Applied!" | P0 | 正在应用 → 成功 / 失败 + 原因 + 下一步 |
| 首次设置向导（`#/welcome`） | P0 | 语言、管理密码、WiFi 名称和密码 |

## 互联网

| 功能 | 优先级 | OpenWrt 实现 | 备注 |
|---|---|---|---|
| 有线 WAN（DHCP / 静态 / PPPoE） | P0 | netifd | GL 插线后的界面本次没看到，需要在 TR3000 上自己设计 |
| 中继：扫描、连接、显示上游信息 | P0 | wpad + netifd（sta 接口 + wwan） | 扫描时要避免打断当前连接 |
| 中继：记住已连接网络并自动切换 | P0 | 自写守护逻辑或 travelmate | 旅行路由器核心体验 |
| 中继：2.4G 强制 20MHz | P1 | UCI wireless | |
| WAN 口改作 LAN 口 | P1 | netifd | TR3000 有两个网口，需求弱于单口机型 |
| USB 手机共享 | P1 | kmod-usb-net-rndis / cdc-ether / ipheth | TR3000 有 USB 3.0 |
| 蜂窝 Modem | — | | TR3000 无内置 Modem，USB Modem 暂不考虑 |
