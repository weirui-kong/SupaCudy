# 无线

![无线页](../screenshots/desktop/02-wireless.jpg)

## 结构

按射频和用途分标签页：本机只有"2.4GHz WiFi"和"2.4GHz 访客 WiFi"两个。双频机型上应该还有 5GHz 对应的两个标签（未在本机观察）。

## 主 WiFi 字段

| 字段 | 选项 / 说明 |
|---|---|
| 启用 WiFi | ON / OFF 开关 |
| 发射功率 | 最大 / 高 / 中 / 低 |
| WiFi 名称（SSID） | 文本 |
| WiFi 加密 | OPEN / WPA2-PSK / WPA/WPA2-PSK |
| WiFi 密码 | 密码框，带显示切换 |
| SSID 可见性 | 显示 / 隐藏 |
| WiFi 模式 | 11n / 11g/n / 11b/g/n |
| 带宽 | 20 MHz / 40 MHz / 20/40 MHz |
| 信道 | 自动 / 1–11 |

- 发射功率和开关放在页面顶部的灰色区域，可以直接改；其余字段默认只读，点"修改"进入编辑态，底部变成"取消 / 应用"。
- 中继启用时，带宽和信道被禁用，⚠ 气泡说明"中继启用时不可修改"（射频要跟随上游信道）。

## 访客 WiFi 字段

启用开关、SSID、加密（同上三种）、密码、SSID 可见性。访客网络的子网和 DHCP 在 [LAN → 访客网络](network.md#lan) 里设置。

## 观察

- 没有 WPA3 选项（MT7628 驱动限制，较新机型应有）。
- 没有"WiFi 二维码分享"入口（部分 GL 机型有，未在本机观察）。
- 定时开关 WiFi 不在这里，而在 [系统 → 定时任务](system.md#定时任务)。
