# 客户端

![客户端页](../screenshots/desktop/03-clients.jpg)

## 列表

分"在线客户端"和"离线客户端"两个可折叠分组，标题带数量。

| 列 | 内容 |
|---|---|
| 名称 | 设备类型图标 + 名称（未识别显示 Unknown） |
| IP + MAC | 两行显示；接入方式图标（2.4G / 5G / 有线）；MAC 旁 ⓘ 提示"这是随机 MAC 地址" |
| 速度 | 上传 / 下载，ⓘ 说明是"打开页面以来最近 3 分钟的平均速度" |
| 流量 | 上传 / 下载累计 |
| 禁止上网 | 开关，直接阻断该设备访问 WAN |
| 操作 | ⋯ 菜单：修改、限速 |

离线分组标题右侧有"删除全部"（清除离线设备记录）。

## 排序和全局操作

页面右上角"按默认排序"+ 齿轮，展开后：默认 / 名称 / IP / 上传速度 / 下载速度，以及"清除流量统计"。

![排序菜单](../screenshots/details/clients-sort-menu.jpg)

## 单个设备的操作

| 操作 | 弹窗字段 |
|---|---|
| 修改 | 名称（留空为自动）；设备类型：台式机 / 手机 / 平板 / 摄像头 / 可穿戴设备 / 笔记本 / 打印机 / 音响 / 电视 / 智能家电 / 游戏机 / 网关 |
| 限速 | 上传、下载限速（KB/s，留空为不限） |

![限速](../screenshots/details/clients-limit-speed.jpg)

## 观察

- 识别了 iOS 等系统的随机 MAC，并主动提示，避免用户以为同一设备是多个。
- 手机端表格只剩"名称 + IP"和"操作"两列，速度、流量和断网开关在手机上不可见，体验明显变差（见 [移动端](../information-architecture.md#移动端390px-宽)）。
- 没有"固定 IP / DHCP 保留"的快捷入口，需要去 LAN 页手动填 MAC（SupaCudy 可以在客户端菜单里直接提供）。
