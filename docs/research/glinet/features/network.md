# 网络

## 防火墙

三个标签页：

| 标签 | 内容 |
|---|---|
| 端口转发 | 规则列表 + "添加"。弹窗字段：名称、协议（TCP/UDP、TCP、UDP）、外部区域（LAN / WAN / guest，默认 WAN）、外部端口、内部区域（默认 LAN）、内部 IP（下拉列出已知客户端 IP）、内部端口、启用 |
| 路由器开放端口 | 让路由器自身的服务（Web、FTP 等）可从外网访问，规则列表 + "添加" |
| DMZ | 启用开关 + DMZ 主机 IP（下拉选已知客户端）；提示开启 DMZ 后端口转发和开放端口规则都失效 |

## 多 WAN

### 接口状态检测

每种上网方式（以太网、中继、热点共享）一行，显示检测方式和目标 IP（默认 ping 1.1.1.1、8.8.8.8、208.67.222.222、208.67.220.220），齿轮打开设置：

| 字段 | 选项 |
|---|---|
| 启用互联网状态检测 | 关闭时只要接口物理连通（插了网线、拿到 IP、中继成功）就认为可用 |
| 检测命令 | ping / httping |
| 检测间隔 | 1 / 3 / 5 / 10 / 15 / 30 / 60 / 300 / 600 / 900 / 1800 秒 |
| 判定失败 | 连续 ping 失败 N 次（默认 3） |
| 判定恢复 | 连续 ping 成功 N 次（默认 8） |
| IPv4 检测 IP | 多个 |

### 模式

- 故障转移（默认）：自动选择可用接口中优先级最高的。
- 负载均衡：同时使用多个接口。
- 强制刷新数据流：接口切换时重置现有连接，让它们改走高优先级接口；代价是网络波动，部分 VPN 可能不会立即重连。
- 接口优先级：默认以太网 → 中继 → 热点共享，可以调整顺序（具体交互本次未验证）。

## LAN

两个标签页：私有网络、访客网络。

- 简单视图：路由器 IP（只让改第三段，`192.168.[x].1`）、最大用户数、起始 / 结束 IP。
- "高级"展开：可设任意私有网段（192.168.0.0/16、172.16.0.0/12、10.0.0.0/8），以及子网掩码、DHCP 网关（DHCP option 3）。
- 下方是 DHCP 地址保留：列表 + "添加"，弹窗字段 MAC、IP、描述；提示客户端需重连才生效。
- 访客网络有独立的网关和地址池设置，没有地址保留。

## DNS

| 设置 | 说明 |
|---|---|
| DNS 重绑定攻击保护 | 开启可能导致内网域名解析失败；有认证门户的网络要关闭 |
| 覆盖所有客户端的 DNS 设置 | 劫持客户端的非加密 DNS 请求 |
| 模式：自动 | 使用上游（以太网 / 中继 / VPN 等）下发的 DNS，并显示当前值 |
| 模式：加密 DNS | 加密方式 DNS over TLS / DNSCrypt-Proxy；提供商 NextDNS / Cloudflare；NextDNS ID |
| 模式：手动 | 最多 4 个 DNS 服务器，下拉内置 Google、OpenDNS、Cloudflare、AdGuard、Quad9 等预设 |
| 模式：DNS 代理 | 填代理服务器地址 |
| 编辑 Hosts | 弹窗里的多行编辑器，静态解析优先于上游 DNS |

## 网络模式

四个大单选卡片：路由器（默认）、AP、中继（Extender）、WDS，每个带一句说明。顶部警告：切换后客户端要重连，切到 AP / 中继 / WDS 后可能无法再访问此页，长按复位键 4 秒可恢复为路由模式。

## IPv6

单个开关。说明 WAN 侧通过 DHCPv6 获取地址，并警告防火墙、VPN、客户端列表、GoodCloud 等不支持 IPv6，与 VPN 同时使用可能泄漏。

## MAC 地址

分段按钮：出厂默认 / 克隆（用当前访问设备的 MAC）/ 手动（可选随机）。分别显示以太网和中继接口的 MAC。说明面向酒店等按 MAC 认证、或不想暴露真实 MAC 的公共热点。

## 旁路由（Drop-in Gateway）

单个开关，需要 WAN 口接到主路由器。让局域网流量先经过本机处理（用于给已有网络加 VPN 等功能）；提示此模式下 VPN 策略对 WAN 口来的客户端无效。

## IGMP Snooping

开关 + 版本（默认 v3，兼容 v1/v2），带较长的原理说明。
