# 互联网

GL 把"上网方式"放在首页，把路由器当成"选一个上游接入"的设备来设计，这是它和 LuCI 最大的思路差异。

## 拓扑总览

- 左侧列出 4 种上网方式：以太网、中继、热点共享（USB 手机）、蜂窝网络；当前使用的高亮，用虚线连到中间的路由器。
- 中间：设备型号图、IPv6 和 VPN 状态图标（中文界面无 VPN 图标）、本机各 WiFi 的小图标（主 WiFi、访客 WiFi）。悬停 WiFi 图标显示对应 SSID。
- 右侧：无线客户端数、有线客户端数，点击跳到客户端页。

## 接口卡片

拓扑图下方每种上网方式一张卡片，标题前有连接状态点。

### 中继（Repeater）

| 元素 | 内容 |
|---|---|
| 标题 | 已连接的上游 SSID + 频段标签（2.4G） |
| 详情 | IP 地址、网关、DNS 服务器、BSSID |
| 操作 | "禁用"（玫红）、"切换网络"（打开扫描列表） |
| 齿轮 → 中继选项 | 允许切换到其他已保存的网络（开）、2.4G 强制 20MHz 带宽（关） |

"允许切换到其他已保存的网络"说明它会记住连过的上游，断开后自动尝试其他已知网络，这是旅行路由器的核心体验。

本次没有点开"切换网络"（会扫描并可能切换上游，导致远程访问断开），扫描列表的样式待补充。

### 以太网

- 没插网线时显示提示"WAN 口检测不到网线，请插入网线"。
- 卡片上直接提供"正在作为 WAN 口使用，切换至 LAN 口"：单网口设备可以把 WAN 口改作 LAN 口用。
- 插线后的 DHCP / 静态 IP / PPPoE 设置界面本次未观察到。

### 热点共享（Tethering）

未插设备时显示"找不到热点共享设备，插入智能手机或 USB Modem 即可启动"。

### 蜂窝网络

未插 Modem 时显示提示；Modem 管理在单独的 `#/modemmanage` 页（本次只看到"未检测到 Modem"）。

## 与其他页面的关系

- 多个上网方式同时可用时，优先级和故障切换在 [网络 → 多 WAN](network.md#多-wan) 里设置。
- 中继启用时，无线页的带宽和信道被锁定（跟随上游），见 [无线](wireless.md)。
