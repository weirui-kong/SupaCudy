# 系统

## 概要

| 卡片 | 内容 |
|---|---|
| CPU 平均负载 | 最近 3 分钟折线图，标注单核 / 多核 |
| 内存使用量 | 最近 3 分钟面积图；ⓘ 说明总量小于物理内存是因为分给了 WiFi 子系统 |

## 升级

- 在线升级：显示是否最新，以及当前版本、固件类型、编译时间。
- 本地升级：拖放上传，支持 .bin / .img / .zip / .tar / .gz。

## 定时任务

三组独立的定时，各自带"应用"按钮：

- LED 显示时段
- 定时重启
- WiFi 定时：模式为"开启 / 关闭"或"切换发射功率"，主 WiFi 和访客 WiFi 分别启用

顶部提示：定时到达时设备关机则不执行，并显示路由器当前时间。

## 管理员密码

旧密码、新密码、确认密码（都带显示切换），以及"禁止弱密码"开关（⚠ 提示）。

## 时区

显示路由器时间 + 时区下拉（453 个时区）。

## 按键设置

图示拨动开关左右两个位置，功能可选：无 / OpenVPN 客户端开关 / WireGuard 客户端开关。简体中文界面下隐藏（因为选项只有 VPN）。

## 日志

标签页：系统日志、内核日志、崩溃日志、云日志、Nginx 日志；右上角"导出日志"，内容区"刷新"。截图中日志内容已模糊处理。

## 重置固件

橙色警告：所有设置、应用和数据将丢失，约需 4 分钟，期间不要断电。一个玫红按钮"全部删除并重启"。
