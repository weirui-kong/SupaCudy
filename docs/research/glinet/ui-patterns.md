# 交互模式

在多个页面里反复出现的做法，按"值得借鉴"和"打算改进"分开记录。

## 值得借鉴

| 模式 | 出现位置 | 说明 |
|---|---|---|
| 页面顶部说明横幅 | 几乎所有设置页 | 浅色底 + ⓘ 图标，一两句话说清这个功能是干什么的、有什么副作用（如"开启 DMZ 后端口转发失效"） |
| 字段旁的 ⓘ 提示气泡 | DNS、VPN 全局选项、多 WAN 等 | 把专业解释藏在悬停气泡里，主界面保持简洁 |
| 字段旁的 ⚠ 提示"为什么不能改" | 无线页的带宽、信道 | 字段被禁用时说明原因（"中继启用时不可修改"），而不是只显示灰色 |
| 改动后才激活"应用" | 所有表单 | 没有改动时"应用"按钮是灰的，避免误提交 |
| 查看 / 编辑两态 | 无线页 | 默认只读展示，点"修改"进入编辑态，底部变成"取消 / 应用" |
| 弹窗统一"取消 / 应用" | 所有弹窗 | 左侧描边按钮取消，右侧实心按钮应用 |
| 危险操作用强调色 | 中继"禁用"、"删除全部并重启" | 危险按钮用玫红实心，和普通的蓝色主按钮明显区分 |
| 空状态带引导 | WireGuard / OpenVPN 客户端和服务端 | 没有配置时给出编号步骤（1. 生成配置 2. 添加节点…）和唯一的主按钮 |
| 卡片状态点 | 互联网页各接口卡片、VPN 仪表盘 | 卡片标题前的小圆点表示连接状态（青色已连接，灰色未连接） |
| 首页拓扑图 | 互联网页 | 左边 4 种上网方式、中间路由器、右边无线 / 有线客户端数，一眼看清"网从哪来、给了谁" |
| 选择器给出常用预设 | 手动 DNS、VPN 提供商 | 下拉里直接列出知名公共 DNS / VPN 提供商，降低填写门槛 |
| 二次说明会断网 | 网络模式页 | 明确告知切换到 AP / 中继 / WDS 后可能无法再访问此页，并给出长按复位 4 秒恢复的办法 |

## 打算改进

| 问题 | 位置 | SupaCudy 的做法 |
|---|---|---|
| 点了"手动添加"就直接创建并保存了一个默认名分组 | WireGuard 客户端 | 先填完再保存；任何写操作都必须由明确的保存/应用动作触发 |
| 主题不跟随系统，且只存在浏览器里 | 顶栏 | 默认跟随系统，提供"系统 / 亮色 / 暗色"三档，见产品规则 |
| 语言存在路由器上，所有人共用 | 顶栏 | 语言是每个浏览器自己的偏好 |
| 手机端只是桌面布局压缩版，客户端表格丢了大部分信息 | 客户端页 | 手机端改成卡片列表，关键状态（在线、速度）直接可见 |
| 中文界面隐藏整个 VPN 功能 | 全局 | 不按语言裁剪功能 |
| 表单字段多为左标签右控件的窄列，宽屏右侧大量留白 | 大部分设置页 | 宽屏用双栏或分组卡片利用空间 |
| 应用设置后只有一个短暂的 "Applied!" 提示 | 全局 | 按产品规则显示"正在应用 → 成功/失败 + 原因" |
| 远程访问链接、高级设置链接等直接暴露完整域名 | 高级设置 | 只显示必要信息 |

## 视觉规律（仅作描述，不复用）

- 侧边栏深色、内容区浅灰、卡片白色，三层明度区分层级。
- 强调色：青色用于"已开启 / 已连接 / 当前选中"，蓝色用于主按钮，玫红用于危险操作，橙色用于警告。
- 开关组件统一用 ON/OFF 滑块；二选一或三选一用分段按钮（如 MAC 地址的"出厂默认 / 克隆 / 手动"，多 WAN 的"故障转移 / 负载均衡"）。
- 列表行高宽松，单行一个设置项，行间细分隔线。
